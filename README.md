| Mechanic        | What happens                                                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Join            | QR invite, name, team of 1–4 and character. Up to 80 players. Host can join as a player.                                                |
| Map             | One seeded map shared by every team: 15 rows, branching routes, visible danger, bosses at 8/15. Projector Map shows team locations.     |
| Deck            | Ten starting cards. Card choices and upgrades last for the run.                                                                         |
| Turn            | Draw five; three energy; play several cards, then End turn.                                                                             |
| Cooperation     | Give allies Block, energy, draws and repeated attacks. Named plays and effects appear on phones and projector.                          |
| Battle          | Choose one of two common cards and one uncommon, or Skip. Gain 20 gold. Hard routes include stronger encounters.                        |
| Elite           | More enemy health and defensive/support enemies. Rare-card choice, relic choice and 35 gold.                                            |
| Rest            | Heal 12, upgrade one card or remove a card. Keep six cards and one Strike/Guard.                                                        |
| Shop            | Separate page with personal stock/wallet. Buy cards or relics, or pay to remove a card. Done readies your own station.                  |
| Gold            | Start with 50. Battles 20, elites 35, boss victories 30. Rewards are once per room; retries do not farm gold.                           |
| Relics          | Twelve passive effects. Inspect descriptions and current use through Cards → Relics. Acquired effects apply to new encounters.          |
| Block/status    | Block absorbs damage and normally clears next turn. Poison ignores Block; Weak/Vulnerable alter damage. Tap effects for rules.          |
| Generated cards | Current encounter only. Exhausted persistent cards return next encounter.                                                               |
| Downed          | Rally costs 3 energy and restores 12 health; normal cards return next turn. Shelter gives an ally 4 Block once per turn.                |
| First arrival   | First team reaching row 8 or 15 calls everyone and earns an additional permanent rare-card offer. Once per gate.                        |
| Questions       | Two Week 6 movement/physics/collision questions before each boss. Every member confirms independently. Named choices reveal after lock. |
| Quiz reward     | Combined team accuracy gives everyone a card offer: below 50% standard ; 50–74% three uncommon; 75%+ two uncommon and one rare.         |
| Boss            | Real decks/health, one shared enemy, up to seven turns. Quiz accuracy also prepares up to 30% less damage on turns 2/4.                 |
| Return          | Middle boss restores each room, piles, energy, shop and clock. Boss health changes carry back. Pending cards wait for a safe choice.    |
| Projector       | Map/Battles switch, stable team rows, visible play queue, question/answer screen, results and attribution.                              |
| Recovery        | Reconnect restores saved play. Restart resumes paused. Receipts prevent repeated purchases, answers and rewards.                        |
